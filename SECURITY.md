# Security policy

Do not open a public issue for a suspected vulnerability or exposed secret. Use
[GitHub private vulnerability reporting](https://github.com/Sebasarabia/aws-security-hub-workflow/security/advisories/new)
when enabled, or contact the repository owner through the private method listed on their profile. Include impact,
affected revision, reproduction with synthetic data, and a suggested mitigation.

This educational reference has no hosted service and no guaranteed support timeline.
Maintainers will acknowledge valid reports when capacity permits. Never test against
accounts or systems without authorization, and never include real findings or secrets.
